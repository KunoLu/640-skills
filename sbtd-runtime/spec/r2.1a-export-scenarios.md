# R2.1a：固定快照 HTML／CSV 导出

范围：D11／D15／D16；冻结 OpenAPI createExport；测试由 `test_exports_http.py`、`test_export_store.py`、`test_export_render.py` 追踪。真实本地 API／文件，无外部服务 mock；故障注入只用于文件发布边界。

```gherkin
Feature: 固定快照的离线报告与完整数据
  Scenario: 接受合法导出并返回作业标识
    Given 已配对的当前本地 session 与尚未过期的快照
    When 提交 HTML 或 CSV 导出请求
    Then 返回 202 且 data 仅包含 export_id
    And 后续可用此标识查询作业和下载产物

  Scenario: 请求严格遵循已批准契约
    Given 已配对的当前本地 session
    When 提交错误格式、畸形 snapshot_id、未知属性或不完整呈现状态
    Then 返回 400
    And 不创建可下载的产物

  Scenario: Panel 顺序必须是完整唯一排列
    Given 当前 manifest 定义全部报告 Panel
    When 提交空、重复、未知或缺少 Panel 的顺序
    Then 返回 400
    But 完整逆序被接受且 HTML 按该顺序展示

  Scenario: 不用新快照替换无效快照
    Given 已配对的当前本地 session
    When 请求格式正确但不存在或在当前 runtime home 不可见的快照
    Then 返回 404
    When 请求已过期的快照
    Then 返回 410

  Scenario: HTML 离线自包含且呈现安全
    Given 包含中日英文本、恶意标题与敏感文本的固定快照
    When 下载 HTML 并离线打开
    Then 所有 manifest Panel、范围、水位和数据质量均可见
    And 不加载外部脚本、样式、字体或网络数据
    And 文本转义且 HTML 和 CSV 使用统一后端脱敏
    And 隐藏系列有说明且明细标注展示数量与总数

  Scenario: CSV 不受页面预览限制
    Given 数据超过一个 cursor 页且页面只预览少量行
    When 导出 CSV
    Then schema 1.1 的全部授权数据族和指标被导出
    And BOM、固定列、空值、公式文本转义保持既有语义

  Scenario: 在途导出保活固定快照
    Given 导出已接受但尚未完成
    When 快照到期且快照清扫运行
    Then 该快照仍可读取且不被删除
    And 导出成功、失败或取消后释放引用

  Scenario: 过期清扫只管理导出目录
    Given ready 产物已保留 24 小时且其他目录存在文件
    When 服务启动或导出清扫运行
    Then 仅清除 exports 内已验证且过期的产物
    And snapshots、数据库、配置、源文件与未知文件不变

  Scenario: 重复下载及重启不改变产物
    Given 已生成且仍有效的导出文件
    When 重复下载并在服务重启后重新配对下载
    Then 字节与 SHA-256 完全一致且保留期限不延长
    And manifest 记录 MIME、大小、范围、Panel、数据族行数和脱敏版本

  Scenario: 下载不能越过授权与路径边界
    Given 服务内存在有效导出
    When 无当前 session、提供其他 runtime home 的标识或尝试路径穿越
    Then 请求被拒绝且无法读取文件
    And 下载接口不接受文件路径参数

  Scenario: 半成品和损坏产物永不被下载
    Given 文件发布发生中断或校验摘要不匹配
    When 查询或下载对应作业
    Then 不返回 ready 文件且不将半成品自动升级
    And 取消仅停止本作业并清理本作业拥有的文件
```
