# R1.0 契约场景

语言决定：本仓库不生成 `.feature`。场景正文为简体中文，结构关键词为英文。领域名词沿用数据字典。

这些场景由 `sbtd-runtime/tests/test_golden_contracts.py` 追踪。它们证明 golden dataset 上的名词、分母和去重，不证明宿主真实 smoke 或 HTTP 服务。

Feature: 观察事件的名词、分母与去重

  Scenario: 相同来源事件重放不增加步骤尝试
    Given golden dataset 中同一步骤开始被相同来源键再送一次
    When 按东京日窗口评估叶子任务
    Then 该重放只被确认
    And 步骤尝试数仍为 4

  Scenario: 相同来源键但内容不同被拒绝覆盖
    Given 一次 Skill 调用开始之后出现同键但结果不同的事件
    When 评估去重结果
    Then 后到事件记为 conflict
    And 保留的调用结果仍是成功

  Scenario: 时间戳不能单独充当去重键
    Given 两个没有来源事件 ID 的事件发生在同一时刻但偏移不同
    When 评估去重结果
    Then 偏移相同且内容相同的重放只被确认
    And 偏移不同的事件被接受

  Scenario: Facade 与宿主看到的同一次调用只计一次
    Given Codex 与 Runtime 都观察到 inv_1
    When 统计组件真实调用
    Then inv_1 只有一个执行对象且保留两个来源
    And 调用总数为 3

  Scenario: 载入 Skill 不是调用
    Given 数据集含 skill.loaded
    When 查询载入指标与调用指标
    Then 载入指标为 unsupported 且值不是 0
    And 调用指标仍为 supported

  Scenario: 完成两次的叶子任务不把父任务算进去
    Given 叶子任务完成、重开、再完成，父任务也完成
    When 用叶子粒度评估
    Then 完成任务数为 1，完成事件数为 2，重开数为 1
    And 父任务不在创建或触达名单里

  Scenario: 窗口边界与跨窗 run
    Given 创建事件正好落在 from，另一个正好落在 to
    And 一个 run 在窗口前开始、窗口内结束
    When 评估窗口
    Then from 上的任务计入创建，to 上的任务不计入
    And 跨窗 run 不计入范围内新启动

  Scenario: 未闭合 run 不是中断
    Given 一个 run 有中断事实，另一个开始后没有结束
    When 评估运行指标
    Then 中断数是 1
    And 未闭合 run 出现在 unknown 名单，而不是中断值

  Scenario: 步骤成功率分母不含阻塞和未知
    Given 有成功、失败、阻塞和未结束的步骤
    When 计算观察到的成功率
    Then 分子是 1，分母是 2
    And 阻塞与未知被单列

  Scenario: 没有可判定样本时不是百分之百
    Given 只筛选没有步骤结束的任务
    When 计算步骤成功率
    Then 样本状态是无可判定样本
    And 值不是 0 或 1

  Scenario: Gate 重试不增加 required 分母
    Given 三个 required Gate，其中一个修正后再审，另有不适用和不确定
    When 计算覆盖率
    Then required 分母是 3，再审次数是 1
    And 只有证据 validated 的通过计入分子
    And declared-only 与 stale 被单列

  Scenario: 首次失败不被后来的通过抹掉
    Given case_a 第一次失败、第二次通过，case_b 第一次通过
    When 计算首次通过率与最终分布
    Then 首次通过率分子是 1、分母是 2
    And 每一轮验证保留自己的最后结果，所以首轮失败仍在分布里

  Scenario: 缺失的 token 和费用不是 0
    Given 一个请求有 token，两个请求没有费用字段，其中一个是 subscription
    When 评估条件性用量
    Then 保留 10 个 input token 和 5 个 output token
    And 缺失请求被点名
    And 费用值不是 0，也不显示为免费

  Scenario: 父子相同请求的用量不双计
    Given 父级 rollup 与子级 detail 携带同一 request 的相同 token
    When 以包含汇总任务的粒度评估
    Then input token 仍是 10，不是 20

  Scenario: 未关联主体和采集缺口保持可见
    Given 一个未绑定主体的事件和一个未关闭缺口
    When 评估采集健康
    Then 未关联数包含该事件
    And 缺口 ID 被返回
    And 没有发生时间的任务进入未知时间集合

  Scenario: 非门禁宿主版本只标记该宿主
    Given 事件来自 codex 0.164.0，而门禁针是 0.163.0 与 omp 18.11.1
    When 评估调用指标和 capability
    Then 0.164.0 为 unsupported
    And 组件真实调用指标仍是 supported

  Scenario: 其余指标预留且不返回 0
    Given 指标目录包含 §8.2 全部 metric_id
    When 评估 golden 窗口
    Then 未纳入核心子集且非条件性用量的指标 support 为 unsupported
    And 它们的值是空，不是 0

  Scenario: 纽约夏令时结束日不是 24 小时
    Given 时区 America/New_York 的 2026-11-01 民事日
    When 计算排他上界前的绝对时长
    Then 时长是 90000 秒
    And 两个 01:30 钟面因为偏移不同而是不同瞬间

Feature: R1 发布门与 API 权限标注

  Scenario: 两门禁宿主都拿不到结构化事件时 R1 不放行
    Given 门禁宿主是 codex@0.163.0 与 omp@18.11.1，capability matrix 声明兜底完成门
    When 两宿主在真实 smoke 中都只能标 unsupported
    Then R1 完成门不通过并回到用户重新决策，不得放行
    And parser fixture 不能代替真实 smoke 的 Skill 或 Tool 调用事件

  Scenario: 导出接口不属于 rc.1 阻塞交付
    Given OpenAPI 草案包含 /api/v1/exports 系列接口
    When 查看这些接口的发布标注
    Then 每个 operation 的发布目标是 v2.1.0-rc.2
    And 它们不是 rc.1 的阻塞交付

  Scenario: Host／Origin 与 CSRF 拒绝共用 403 契约
    Given 本地 API 按 ADR Q5 校验 Host／Origin，unsafe 方法另要求 CSRF
    When 查看 OpenAPI 的 responses
    Then 存在一个可复用的 403 响应组件，覆盖 Host／Origin 拒绝与 CSRF 拒绝
    And 所有接口通过引用使用它

Feature: 创建 HTML／CSV 导出的请求契约

  本节仅验证 OpenAPI，不证明导出服务已经实现；由 OpenApiDraftTests 的
  test_create_export_* 追踪。presentation_state 沿用 ReportDocument 的七字段模型。

  Scenario: 固定快照并选择当前支持的导出格式
    Given 客户端已有完成的快照 snap_0123456789abcdef0123456789abcdef
    When 按 createExport 契约提交 application/json 请求
    Then 请求体必填且 snapshot_id 与 format 必填
    And html 和 csv 均可接受，省略 presentation_state 也可接受
    And snapshot_id 必须完整匹配 snap_ 后跟 32 位小写十六进制字符

  Scenario: 呈现状态不成为数据筛选
    Given 呈现状态含主题、报告宽度、展开明细、排序、预览行集、Panel 顺序和图例状态
    When 客户端随固定快照提交完整 presentation_state
    Then 七个字段按既有 ReportDocument 类型验证
    And 报告宽度与预览行数必须非负，零与小数仍可接受
    And 呈现状态只能影响显示，不改变 CSV 数据范围

  Scenario: 拒绝不完整或不支持的导出请求
    Given createExport 只开放 html 和 csv
    When 请求缺必填字段、快照 ID 格式错误、数值为负、使用 jpeg／pdf／未知格式、类型错误或多余字段
    Then 请求不符合 schema，契约声明 400
    And 显式提供的 presentation_state 必须完整且类型正确

  Scenario: 缺失与过期快照不被静默替换
    Given 请求引用固定 snapshot_id
    When 查看 createExport 的错误响应契约
    Then 不存在或不可见的快照声明 404
    And 过期快照声明 410，不复用旧 ID 创建新快照
