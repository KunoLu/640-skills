## §20.3 需求一完成核对

不启动 Dashboard 的情况下，对本机已授权的 SBTD 执行可以：采集（facade 注册 + 适配器 + 历史导入）、追溯（history_read 列表与 task_history）、分级（capability matrix 与 evidence_status）、去重（来源键确认／冲突）、查询（stats_query 半开窗口 + contract_eval 口径）、固定快照（共享 snapshot_id、迟到新 id、过期 gone）、完整 CSV（`export_schema_version` 1.1 全范围遍历）；不能采集的范围（unsupported 宿主、未知时间、缺 token／cost）如实可见且不填 0。
