## Graft structural evidence (managed)

This project is wired to the pinned local Graft CLI (@nanonets/graft@0.18.0) by the SBTD onboard CLI, the only writer of this fence and of the Codex MCP/hook entries. The managed launcher proves the selected graph before forwarding each MCP request; native post-launch refresh remains disabled.

- For structure queries use the registered local Graft MCP server bound to this exact repository root (the `sbtd-graft-<hash>` entry in the active Codex `config.toml`). The installed managed launcher (`sbtd_graft_entry.py`) behind that entry and the authorized hooks is the only managed launch path; never spawn upstream `graft`/`npx` servers or hook shims directly. The launcher still reads the current graph per request, so a rejected graph remains unavailable to MCP even while an authorized Stop hook or explicit deployment build can create the next graph.
- The wiring binds this repository root only. Never run Graft against a parent directory, a sibling checkout or any unselected project; nested repositories need their own explicit per-root setup.
- If the managed launcher fails its guard (fixed stderr message, exit 2), stop using Graft here and ask the user for an explicit wiring re-init through the onboard CLI. Never repair, bypass or replace the guard, never run upstream `graft init`/`mcp`/hook shims, and never hand-edit MCP/hook configuration as a workaround.
- Always prohibited: telemetry, `--deep`, `blast --name` or any other LLM symbol naming, brain connect/cloud and any cloud or custom-provider activation, automatic LLM enrichment, and publishing graphs, blasts, code or query output to PRs, public viewers or knowledge services. Do not set, print or persist `GRAFT_API_KEY` or other provider keys; managed children start with Python startup environment isolation (`-E -s`), run with `DO_NOT_TRACK=1`, and use a scrubbed LLM/cloud environment.
- Graft output is downgradable structural evidence, never proof: an empty result or exit 0 does not prove no impact, and conclusions still need source/LSP confirmation. If the graph is missing, stale or blocked, continue with source reading and report Graft as skipped/blocked. Hooks are a separate persisted opt-in; absent hooks are not a failure and must not be fabricated.
