## Codex

### v0.139.0 -> v0.140.0

来源与版本判断：

- GitHub Releases 已发布稳定版 `rust-v0.140.0`，发布时间为 2026-06-15T21:06:37Z；GitHub release 标记 `prerelease=false`。
- npm `@openai/codex` 的 `latest` dist-tag 为 `0.140.0`，各平台包 dist-tag 也同步到 `0.140.0-*`。
- GitHub 和 npm 同时存在更新的 `0.141.0-alpha.2`，但本工具版本通道策略是 `stable-only`，因此本次只比较稳定版 `v0.139.0 -> v0.140.0`。
- GitHub compare `rust-v0.139.0...rust-v0.140.0` 显示 194 个提交、300 个变更文件；release notes 足以支撑本次分析。

Release 汇总：

- 新增 `/usage`，用于查看每日、每周和累计账号 token 活动。
- `/goal` 改进了超长文本、大块粘贴内容和图片附件的保留能力，也覆盖 remote app-server session。
- 新增永久删除会话能力，包括 `codex delete`、`/delete` 和 app-server `thread/delete`，并包含确认保护和 subagent 清理。
- 新增 `/import`，可选择性导入 Claude Code 的 setup、project configuration 和近期聊天。
- 输入 `@` 默认打开统一 mentions 菜单，覆盖 files、plugins 和 skills。
- 增加托管 Amazon Bedrock API key 认证，并为 CLI 与 MCP OAuth 凭据提供加密本地存储。
- SQLite 状态库损坏时会自动备份并基于 rollout 数据重建，也覆盖数据库目录异常情况。
- MCP 启动可靠性提升：会重试 transient startup failures，能把不可用 OAuth 凭据报告为 logged out，并保留显式禁用的 servers。
- 修复 remote plugin uninstall 请求，并正确暴露安装时需要认证的 apps。
- 非 TTY 后台命令现在可用 Ctrl-C 中断，同时保留最终输出和退出状态。
- 大仓库和长会话响应性有改进，包括保留 Git fsmonitor、减少 rollout history 重读、加速 archive lookup、缓存 turn diff rendering。
- TUI 删除了实验性 `/realtime` voice controls 和相关 audio 依赖。

破坏性变更：

- release notes 未标注明确 breaking change。
- 需要注意的是，新增的永久删除命令会真实删除会话；自动化或脚本不得把它当作普通清理命令隐式调用。

迁移说明：

- 当前 `ENTRYPOINT.md` 只作为每日自动化比对基线，本次不写回版本号。
- 如果用户后续手动输入 `更新` / `update`，再将 Codex 当前使用版本从 `v0.139.0` 写回到 `v0.140.0` 并归档本文件。
- 安装侧可继续使用 npm `latest`，npm metadata 已确认 `@openai/codex@0.140.0` 存在并提供 `codex` bin。

对 agent harness workflow 的影响分析：

- 本地规则关键词扫描覆盖 `AGENTS.md`、`kuno-workflow-onboard-skills/SKILL.md`、`REFERENCE.md`、`scripts/onboard.py`、`templates/agents/*.md` 和 `templates/skills/**/SKILL.md`。
- 扫描命中主要集中在既有 AGENTS 优先级、MCP 可用性、secret 不入库、onboard 安装边界和 GitNexus/TestSprite MCP 配置说明；这些规则已经覆盖 release 中的 MCP、OAuth、凭据安全和 AGENTS 模板边界，不需要新增长期规则。
- `/usage`、`/goal`、`/delete`、`/import` 和 `@` mentions 都是 Codex 操作能力增强，不改变本仓库的每日版本检查、同步、更新或 onboard Skill 安装流程。
- `codex delete` / `/delete` 属于高风险用户显式操作；本自动化没有调用，也不需要写入普通 workflow 模板。
- 没有修改 `AGENTS.md`、`kuno-workflow-onboard-skills/templates/agents/*.md` 或 `templates/skills/**/SKILL.md`。
