# UPDATE

## Codex

### v0.134.0 -> v0.135.0

来源：

- GitHub Releases：<https://github.com/openai/codex/releases>
- 对比区间：<https://github.com/openai/codex/compare/rust-v0.134.0...rust-v0.135.0>

版本判断：

- `ENTRYPOINT.md` 监控表中的当前使用版本是 `v0.134.0`。
- 最新稳定 release 为 `0.135.0`，对应 tag `rust-v0.135.0`，发布时间为 2026-05-28。
- `0.136.0-alpha.1` 已出现，但属于 prerelease；当前策略为 `stable-only`，本次不纳入目标版本。

Release 汇总：

- `codex doctor` 增加环境、Git、终端、app-server 和 thread inventory 诊断信息，更适合排查 Codex 运行环境和支持问题。
- TUI 的 `/status` 在远程 transport 场景下会显示远程连接细节和 server 版本。
- Vim mode 增加 text-object 编辑、改进 word / line-end 行为，并允许配置 interrupt-turn 绑定。
- `/permissions` 支持 named permission profiles，并能显示已配置的 custom profiles。
- 打包版 Codex 可在 macOS 和 Linux 目标上发现并使用 bundled patched zsh helper。
- Python SDK 为 thread / turn API 增加更友好的 `Sandbox` preset。
- TUI Markdown 表格和多行列表渲染更清晰，macOS 与 Zellij 下的输出稳定性提高，slash-command completion 会保留已有草稿文本。
- resume flow 能纳入 non-interactive exec sessions，并尊重 idle cached thread 的 cwd override。
- 文档更新了 image-viewing tool detail 行为、移除过期 TUI composer 叙述，并补充 Python SDK sandbox preset 用法。
- 内部维护包含 Rust toolchain / SQLx / SQLite 升级、memory runtime state 迁移到独立 SQLite 数据库、清理 legacy config-profile consumer、集中 Responses retry 与 MCP tool naming 逻辑。

破坏性变更：

- release notes 未标出面向 agent harness 使用者的 breaking change。
- 需要注意的是，release notes 提到 legacy config-profile consumer 被移除并改由 app-server-owned API 承接；本仓库现有规则未要求手工维护这类 legacy config profile，因此不需要迁移本仓库配置。

迁移说明：

- 常规升级到 `v0.135.0` 即可。
- 如果排查 Codex 运行环境、app-server、终端或 thread inventory 问题，可优先查看新版 `codex doctor` 输出。
- 如果自动化依赖 Python SDK 的 sandbox 配置，可后续评估是否迁移到新的 `Sandbox` preset；本仓库没有相关 SDK 代码。

对 agent harness workflow 的影响分析：

- 命中本地规则扫描关键词：`permission profile`、`app-server`、`MCP`、`SQLite`、`Sandbox` 等只出现在现有通用描述或 release 记录中，没有发现本仓库长期规则依赖旧 config-profile consumer 的写法。
- `codex doctor` 诊断增强属于可用排障手段，但不改变本仓库每日版本检查、Trellis / GitNexus / Graphify 使用边界，也不要求新增强制验证步骤。
- `/permissions`、`/status`、Vim mode 与 TUI 渲染改进改善交互体验，不改变本仓库 AGENTS / Skill 的执行规则。
- 本次不修改 `AGENTS.md`、`agents/AGENTS.global.md`、`agents/AGENTS.project.md` 或 `skills/**/SKILL.md`。
