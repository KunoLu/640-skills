# UPDATE

## Codex

### v0.142.5 -> v0.143.0

本次检测到 Codex 已发布新的 stable 版本。GitHub release `rust-v0.143.0` 于 2026-07-08 01:31:10 UTC 发布，npm `@openai/codex` 的 `latest` dist-tag 也指向 `0.143.0`，平台包 dist-tag 同步存在 `linux-x64`、`linux-arm64`、`darwin-x64`、`darwin-arm64`、`win32-x64` 和 `win32-arm64`。`0.144.0-alpha.1` 以及 `rust-v0.144.0-alpha.*` 等 alpha 预发布版本仍按 stable-only 策略忽略。

来源依据：

- GitHub release：<https://github.com/openai/codex/releases/tag/rust-v0.143.0>
- GitHub compare：<https://github.com/openai/codex/compare/rust-v0.142.5...rust-v0.143.0>
- npm metadata：<https://registry.npmjs.org/@openai/codex>

Release 汇总：

- Remote plugins 默认启用，catalog 展示更丰富，能显示 npm marketplace 来源和 remote / local 版本信息。
- Codex 可通过 macOS / Windows 系统代理路由认证和 Responses API 流量，覆盖 PAC / WPAD 场景。
- 新增 `codex remote-control pair`，用于从运行中的 daemon 生成手动 pairing code。
- Amazon Bedrock 模型目录新增 GPT-5.6 Sol / Terra / Luna，并把 `max` reasoning effort 作为一等配置。
- MCP tools 默认走 tool search；ChatGPT-hosted MCP servers 可以显式使用 session authentication。
- App-server client 增强了环境查看、descendant threads 列表、按 turn fork history 等能力。
- 修复包括 Windows ConPTY 输入、sandbox credential retry、MCP startup busy 状态、remote-control token refresh retry storm、WebSocket incremental request metadata 比较、GitHub API rate limit 下的 installer 稳定性等。
- 依赖安全维护包括 OpenSSL、Hono、fast-uri、quick-xml 和 crossbeam-epoch 更新。

破坏性变更：

- Release notes 没有标记明确 breaking change。
- 但 remote plugins 默认启用和 MCP tools 默认通过 tool search 暴露，会改变 Agent 可见工具面的发现方式；catalog 中看到 plugin / connector 不等同于当前会话已经可调用或已授权。

迁移说明：

- 不需要在本仓库每日自动化中写回 `ENTRYPOINT.md`；版本基线仍保持 `v0.142.5`，只有用户手动输入 `更新` / `update` 时才写回。
- 使用 plugin / connector / ChatGPT-hosted MCP 时，应先以当前会话暴露的工具、`tool_search` 或 MCP 可见性检查作为强证据。需要安装 plugin / connector 时，只在用户明确点名且安装工具返回精确匹配后请求安装。
- Session authentication / OAuth / cookies / tokens 只能通过 Agent 或 connector 管理，不写入仓库、日志、报告或 MCP 配置示例。
- 系统代理支持属于 Codex runtime 行为；除非用户明确要求，不应替用户改 OS proxy、PAC 或 WPAD 配置。

对 agent harness workflow 的影响分析：

- 关键词扫描范围：`AGENTS.md`、`kuno-workflow-onboard-skills/SKILL.md`、`kuno-workflow-onboard-skills/REFERENCE.md`、`kuno-workflow-onboard-skills/scripts/onboard.py`、`kuno-workflow-onboard-skills/templates/agents/AGENTS.global.md`、`kuno-workflow-onboard-skills/templates/agents/AGENTS.project.md`、`kuno-workflow-onboard-skills/templates/skills/**`。
- 扫描关键词：`tool_search`、`remote plugin`、`plugin`、`connector`、`session auth`、`ChatGPT-hosted`、`remote-control`、`system proxy`、`PAC`、`WPAD`、`app-server`、`descendant`、`fork history`。
- 命中结果：现有文件只覆盖 MCP 工具可见性检查和 React Bits Pro 项目级 Skill，缺少 Codex remote plugin / connector、延迟 tool discovery、session auth 和系统代理边界。
- 处理决定：已最小化更新全局 AGENTS 模板、项目级 AGENTS 模板和 onboard reference，补充 Codex plugin / connector / `tool_search` / session auth / system proxy 的长期通用规则；同时同步更新 README.md 和 README.html 中的工具边界说明。
- 未处理项：`codex remote-control pair`、Bedrock GPT-5.6 模型、app-server descendant thread / fork history 对本仓库当前模板没有直接工作流规则变化，只记录在本版本分析中，不写入长期规则。
