## Codex

### v0.136.0 -> v0.137.0

### 版本判断

- 当前基线：`ENTRYPOINT.md` 中 `Codex` 的当前使用版本为 `v0.136.0`，版本通道策略为 `stable-only`。
- 最新可比较版本：GitHub Releases 已发布稳定版 `0.137.0`，tag 为 `rust-v0.137.0`，发布时间显示为 2026-06-04；同页更高的 `0.138.0-alpha.1` 到 `0.138.0-alpha.4` 均为预发布版本，按 `stable-only` 忽略。

### Release 汇总

- TUI 与交互：支持 F13-F24 keybindings、可搜索菜单粘贴，以及 reasoning-only 的状态 / 标题项；slash-command 过滤、footer shortcut hint、取消已提交 prompt 后恢复草稿等交互细节也有修复。
- 企业 / 管理配置：新增月度 credit limit 展示，以及 cloud-managed config bundle 能力，包含 EDU workspace 相关配置层。
- Remote control：app-server v2 RPC 支持发起 pairing，并可列出或撤销 controller grants。
- 工具与插件：`codex plugin list --json` 增加机器可读输出，远程 catalog suggestion 有缓存；hosted web / image tools 在更多 code-mode flow 中可用，standalone web search 可并行执行。
- 多 Agent / Subagent：multi-agent v2 保留每个 thread 的 runtime choice，并调整 follow-up 和 metadata 默认值；release 还包含 spawned child listener raw events、subagent lineage / follow-up 相关变更。
- 权限与平台可靠性：permission request / approval 携带 environment identity；managed MITM proxy 会向 child commands 导出可读 CA bundle；macOS app launch、Windows SQLite startup、thread resume、sandbox setup refresh 等平台可靠性增强。
- 文档 / 构建：新增 app-server 文档和 schema 更新；仓库 review rules 与 contributor conventions 迁入上游 `AGENTS.md`；Rust release 的 Cargo fetch 改用 git CLI；Python SDK runtime wheel 发布和 glibc runtime pinning 继续演进。

### 破坏性变更

- GitHub release notes 没有标记必须迁移的破坏性变更。
- 本次包含 enterprise/cloud config、permission approval environment identity、managed MITM CA bundle 等配置和运行时增强；从 release notes 看，这些不要求本仓库模板立即修改。

### 迁移说明
