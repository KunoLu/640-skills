# UPDATE

## Playwright v1.61.1 -> v1.62.0

### 检测结论

`ENTRYPOINT.md` 的固定基线为 `v1.61.1`，版本通道为 `stable-only`。GitHub 最新稳定 release 是 `v1.62.0`，发布于 2026-07-24；因此本次区间为 `v1.61.1 -> v1.62.0`。本自动化没有写回 `ENTRYPOINT.md`。

### Release 汇总

- 组件测试切换到 stories / galleries 模型：以具名 story 承载固定 props、mock 和 provider，`fixtures.mount()` 返回限定在 story 根节点的 Locator，并支持 `update(props)` 与 `unmount()`。
- 大多数操作和 web-first assertion 新增 `AbortSignal`，可取消长时间 action、navigation、wait 和 assertion；默认 timeout 仍然生效。
- 截图断言与截图 API 支持 WebP；reporter 新增 `preprocess()`，可在运行开始前调整单个测试的运行状态；失败重试可选 `retryStrategy: 'isolated'`。
- Playwright 发行包现在内置 Playwright MCP server 和 `playwright-cli`，可通过 `npx playwright mcp` 与 `npx playwright cli` 启动。
- Debian 11 不再受支持；浏览器版本升级到 Chromium 151、Firefox 153、WebKit 26.5。

### 破坏性变更与迁移

- 使用 Playwright 组件测试的项目需要按新版 stories / galleries 模型迁移；本仓库模板未配置组件测试，因此没有迁移动作。
- Debian 11 上的 Playwright CI 或本地环境不再受支持；本仓库不维护对应运行镜像或平台 pin，未新增平台规则。
- MCP server 入口从独立包可迁移至发行包内置入口。为保持与仍未暴露该入口的安装兼容，Onboard 改为优先使用发现到的 `npx playwright mcp`，否则继续要求配置兼容的专用 server；MCP 可见性确认和其“不替代项目级 Playwright CLI”的边界不变。
