### 发布汇总

本区间是 OMP CLI/runtime 的 patch 修复，不是新的工作流命令、配置键或安装路径。进入 `@oh-my-pi/pi-coding-agent` 的变化：

- 既有能力修复：Ask 自定义答案在粘贴后不再要求再次提交，也不再停在同一道多选题；待提交剪贴板文本会在提交前保留，单题多选仍走 review（`#11099`）。
- 既有能力修复：`/copy` 链接说明不再显示 Markdown 分隔符，多行标签不再拆成两行（`#11086`）。
- 既有能力修复：运行中的 mid-turn steering 不再替换 `/loop` 重复提示；运行中的 steering 是一次性的，只有空闲提交才会成为新的 loop body（`#11159`）。
- 既有能力修复：Codex Astra 的更大窗口默认关闭，需 Extended Context 才启用；关闭后包括缓存模型也不再保留大窗口；显式模型覆盖仍优先。SDK embedding / early boot 不再静默打开 Extended Context（`#11126`、`#11157`）。
- 既有能力修复：显式 Codex context-window 覆盖不再超过服务端认可上限；Astra 扩展窗口按文档使用 922K input / 1.05M 总上下文，超过 272K input 的 Astra API 请求按文档长上下文计价，Codex 订阅路由仍豁免（`#11157`）。
- 既有能力修复：LSP idle timeout 按 workspace client 计算（`#8389` / `#10237`）。
- 既有能力修复：父进程退出时回收孤立 IPC subprocess workers（`#11141`）。
- 既有能力修复：有未完成 async job 时推迟 idle compaction（`#10223`）。
- 既有能力修复：启动更新公告会统计 `###` 标题上方的条目，并忽略独立分隔线；`+` / `*` 与轻微缩进的 bullet 按 `-` 计数。
- 文档：`tab.evaluate` 字符串语义说明（`#11114`）。这是 browser 文档澄清，不是新的 browser API。
- 依赖 runtime：GitHub Copilot reasoning-off 的 `Supported values` 拒绝会重试最低允许 effort；Cursor GPT off-tier 不再发送原始 `-none` sibling id（`#11128`）。这些进入 OMP 模型请求路径，但不是本仓库 AGENTS / Onboard 配置。
