### v0.8.18 -> v0.8.20

本次比对来源：GitHub Releases / GitHub tags / GitHub API，并用 PyPI `graphifyy` release history 交叉确认。GitHub tags 中已出现 `v1.0.0`，但该 tag 指向 2026-04-05 的旧提交，`pyproject.toml` 中包版本仍为 `0.1.10`，`v0.8.18...v1.0.0` compare 显示与当前 `v0.8.x` 线分叉且落后 530 个提交；因此判定为非当前包发布线的旧 tag，不作为本次 stable-only 目标。当前已完成 release-note 和包元数据分析的稳定包版本为 `v0.8.20`；本次汇总 `v0.8.19` 和 `v0.8.20`。

- release 汇总：`v0.8.19` 增加 `.sln`、`.csproj`、`.fsproj`、`.vbproj`、`.razor`、`.cshtml` 抽取，支持 NuGet、项目引用、target framework、Razor / Blazor 指令、component 引用和 `@code` 方法；中文查询增加 `jieba` 可选分词和字符 bigram 回退；修复 `source_file: null` wiki TypeError、嵌套 `.claude/worktrees/` 被索引、TypeScript 5 array-form `extends`、backup 积累，并加入 Devin CLI 支持。`v0.8.20` 修复 Windows 删除 / 移动文件后的 ghost nodes，增加 XML DoS 预筛和 `extract_lpk` size cap，修复 Dart node ID 嵌入绝对路径，稳定 `cluster-only` 标签映射，并新增 MCP config extractor，抽取 MCP server、npm / pip 包引用和 env var 需求但丢弃 env 值。
- 破坏性变更：Dart 旧图谱可能保留绝对路径 node ID；release notes 建议已有 Dart graph 使用 `graphify extract --force` 重建。MCP config extractor 明确丢弃 env values，不能把 Graphify 当作凭据读取来源。
- 迁移说明：使用 Graphify 分析 Dart 项目时，应在升级后强制重建图谱；分析 .NET / Razor / MCP 配置或中文查询时，应确认当前安装包含对应能力或可选 extra。
