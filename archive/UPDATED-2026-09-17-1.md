### Release 汇总

区间覆盖 `v18.2.1` 与 `v18.2.2`。以下只保留进入 `@oh-my-pi/pi-coding-agent` CLI / runtime 的条目。

#### v18.2.1（破坏性 + CLI）

破坏性：

- `/drop` 斜杠命令改名为 `/delete`，避免与 `/goal drop` 语义冲突。
- Read 工具结果不再把正文复制到 `details.truncation.content`；应使用 result `content` 或 `details.displayContent`。
- 删除 hashline 编辑操作 `DEL`、`DEL.BLK`、`COPY`、`COPY.BLK`。删除改用 `CUT` / `CUT.BLK`；剪下内容仍可 `PASTE`。
- `tab.screenshot()` 不再接受单次保存路径；截图写入 `browser.screenshotDir`（未设置则用系统临时目录）并返回保存路径。

CLI / runtime 新增与行为变化（摘）：

- hashline 增加 `CUT` / `PASTE`（含 `.BLK`）；跨 section、跨 edit 调用可保留 register。
- MCP 服务器名允许空格，人类可读 display label（如 `MaaS Slack`）可在 `/mcp reauth` 写回时保留。
- 新增 `--from-claude` / `--from-codex` 会话导入，以及 `/resume @claude`、`/resume @codex`。
- 新增 `omp cleanse`：检测语言生态检查器、解析诊断、分发给并发 subagent 并做验证。
- `inspect_image.enabled` 布尔改为三态 `inspect_image.mode`（`auto`|`on`|`off`，默认 `auto`）；旧 `true/false` 迁移到 `on/off`。
- 启动 changelog 默认改为条数摘要；`startup.changelogMode` 为 `summary` | `expanded` | `hidden`；旧 `collapseChangelog` 自动迁移。
- `task.enableEffort` 默认 false，不把 per-spawn `effort` 放进 schema，直到显式打开。
- MCP 工具名不再丢掉数字（例如 `context7` 不再变成 `context`）；旧 digit-stripped `tools.approval` 的 `deny`/`prompt` 仍适用，`allow` 与精确 `xdevInlineDevices` 需改新名。
- `hub start` 在 stale broker lease 时改为进程锁；`hub wait` / 只读 subagent 注入 `hub` 等边界收紧。
- `/handoff` 继续是生成 handoff 文档并压缩当前会话，不是开新会话（v18.2.2 只修正文案）。

#### v18.2.2（CLI 修复与加固）

- 内置 secret obfuscation 扩展到连接 URL 中的口令（不依赖环境变量名）以及 AWS / Google / Slack / npm / Stripe / Hugging Face / SendGrid / JWT / Bearer / PEM。
- 新增 `tui.titleSpinner`（`braille` / `dots` / `line` / `pulse`）。
- 带 reason 的 session-stop hook 会阻止会话结束，直到 hook 放行或用户中断；显式 abort 不再被 stop hook 重启。
- 损坏的 agent / prompt-history / credential 数据库先做私有备份再重建，启动可继续；凭证可能需要重新登录。
- 从 Agent Hub 停止 subagent 会结算并上报父 background job，不再让 `hub wait` 无限阻塞。
- 修复 `security-reviewer` 对带 anchor 与 remediation 的合法 findings 的接受。
- 修复 `--prewalk-into @default` 被显式启动模型覆盖默认 role 的问题。
- 损坏或被外部改写的 session 文件不再无法关闭；随后 Ctrl+C 可退出且不重写 session log。
- 静默 MCP 请求不再被未声明 idle timeout 掐断；关闭 legacy SSE 会取消挂起请求。
- 显式模型刷新会重新求值 command-backed API key / header。

### 破坏性变更

对升级到 `v18.2.2` 的 OMP CLI 用户：

1. 会话删除命令从 `/drop` 改为 `/delete`。
2. 依赖 `details.truncation.content` 的扩展 / 脚本需改读 `content` 或 `details.displayContent`。
3. hashline payload 不得再发 `DEL` / `COPY` 系列；删除与移动只用 `CUT` / `PASTE`。
4. browser screenshot 不再接受 per-call path。
5. `inspect_image.enabled` 配置键迁移为 `inspect_image.mode`。
6. MCP tool 的 digit-preserving 重命名：精确 `allow` 策略可能失效，需对照新名。

### 迁移说明

- 升级 npm / 二进制到 `@oh-my-pi/pi-coding-agent@18.2.2`（GitHub tag `v18.2.2`）。本自动化不写回 `ENTRYPOINT.md`。
- 旧 `settings.json` → `config.yml` 迁移改为先写 YAML 再归档 JSON；失败会暴露而不是吞掉。
- `collapseChangelog` 自动迁到 `startup.changelogMode`。
- MCP 精确 allowlist 与 `xdevInlineDevices` 若使用去数字旧名，升级后需人工对照。
- 损坏 DB 会备份后重建：启动成功不代表旧凭证仍在。
