# ADR 0004：R2.1b 库级独立 JPEG／PDF renderer

> 状态：accepted（内部实现；不授权 HTTP 格式变更）
> 日期：2026-10-22
> 范围：D3／D4／D16、PRD §13.5–13.7。OpenAPI、Panel manifest、PRD、ADR 0001–0003 与 CSV schema 均不修改。

## 1. 输入与所有权

`ExportRenderer(snapshots, home=home)` 在 JPEG／PDF 分支调用独立 browser renderer。输入仍是固定 Snapshot 与 presentation state，不是任意 URL、HTML 或用户浏览器页面。浏览器源文档由现有 `export_render.render_export(..., 'html', ...)` 生成；event-detail 的 exportable／classification 过滤、脱敏、Panel 数据绑定及 withheld 告警不另写一份。

JPEG 固定 1440 CSS px 的报告宽度。呈现状态只影响显示，不改变指标或 CSV 数据范围。用户 2026-10-22 11:13 +08:00 决定保持 #151：event-detail 行可被屏蔽，派生 task／run／aggregate 不按事件标志过滤；这不是整任务保密规则。

ExportStore 仍唯一拥有 exports 文件、manifest、SHA-256、原子发布、ready 后 24h 保留与启动清扫。所有格式在接受前 pin，终态 release；renderer 返回字节与元数据，不写第二条持久产物路径。临时 browser 工作目录不是 ready artifact，不可下载。在途作业不跨服务重启重放。

## 2. 可选依赖

`requirements-renderer.txt` 精确固定 PyPI `playwright==1.64.0`，受控 Chromium headless shell 156.0.8078.4（revision 1248）随该版本固定。`PLAYWRIGHT_BROWSERS_PATH=$SBTD_RUNTIME_HOME/browsers` 与 `playwright install --only-shell chromium` 将浏览器安装在扩展自有目录。不在业务项目装依赖，不复用系统 Chrome 或用户 browser cache，不在运行导出时自动下载。

Linux 受控环境的 `renderer-system-dependencies.txt` 固定 `fonts-noto-cjk=1:20240730+repack1-1`；字体不入仓。其他平台独立验证，不把 Linux 结果推广为跨平台通过。安装必须事先授权；下载、解压体积和 venv／字体的独立占用在安装文档说明。

缺依赖仅影响 JPEG／PDF；HTML／CSV 继续走标准库渲染。Capabilities 提供安全原因，并区分库级 `available` 与 HTTP `http_available`。依赖预检不代替每次浏览器启动与作业结果。

## 3. 隔离与资源生命周期

一个作业一个独立 Python 子进程、一个新建临时 profile；不带入用户 cookies／登录态。主进程信号量串行 JPEG／PDF（含直接库调用），服务现有实例锁保持单 runtime writer。等待、浏览器操作和整个作业均有超时／取消边界；终止只针对本作业进程树，再删除本次拥有的临时目录。

Chromium 显式使用 `chromium_sandbox=False`；这里不提供 OS sandbox 保证，也不通过自动探测暗示额外保护。隔离由固定报告输入、作业独占 profile、路由禁网及有界进程生命周期组成，不能抵御浏览器漏洞。需要 OS sandbox 的环境须另行定义并实测启动策略，不把应用级隔离当作替代品。

浏览器仅接收一次内存报告主文档；路由层拒绝其他请求，包括外部 HTTP(S)、子框架和任意 file 访问；禁止 service workers。测试用外部图片、fetch、file 探针验证拦截；注入 seam 仅在内部测试使用，不作为公共任意 HTML 接口。路由拦截和独立 profile 是应用级隔离，不声称能抵御已控制同机账号／管理员或浏览器漏洞。

失败只向 ExportStore 返回固定安全错误码，不传出 Chromium stderr、临时文件路径或源文档。没有自动重试、后台守护进程或新队列；不新增与本任务无关的配额／淘汰策略。

## 4. 图像与打印

JPEG：1440 CSS px、默认 2x、quality 90、full-page、opaque background、当前主题。等待 `document.fonts.ready` 与确定性布局／图片就绪；关闭动画及遮挡布局。对实际尺寸向上取整，检查单边 32,000 px 与 80,000,000 pixels；2x 不满足则完整降至 1x 并记 warning，1x 仍不满足则安全失败，绝不裁断／分包／零字节成功。

PDF：明确打印样式，A3 landscape、四边 10mm、print background。报告宽度适应可打印区域；表头使用 table-header-group、行避免中间切断、长 Panel 可分页，不给全部 Panel 强加 break-inside avoid。页脚含报告标题、范围、snapshot_id 简写和页码。保留文字／SVG，不能把 JPEG 塞入 PDF 冒充可搜索文档。中日英嵌入字体与文本抽取由真实浏览器验收，逐页视觉与跨平台完整 AC-51 仍按 R2.2 范围执行。

## 5. 冻结契约与回滚

本期 `POST /api/v1/exports` 仍只接受 html／csv；JPEG／PDF 返回 400。新格式枚举、图片超限和 renderer 不可用错误协议由独立 contract PR 确定，详情见 R2.1b task.md 的 CONTRACT-CHANGE-NEEDED。自由 Json capabilities 不得被解释成格式请求已获授权。

回滚只撤回代码，不删除 audit.db、snapshots、exports 或用户已下载文件；不迁移数据。旧实现不能创建新格式，但持久文件仍保留。卸载浏览器／字体或销毁 smoke 证据是单独操作，不由自动清扫处理。
